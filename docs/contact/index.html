Contact

Cirrus is made by Neighborhood Nerd. These are the ways that actually reach us.

Updated November 4, 2026

In short

There isn’t a public support inbox yet. Use Discord for chat, GitHub for a public issue, or Report a bug in the app if you can attach logs. How-to answers live on the Support page first.

Chat

Discord

The Cirrus community server. Same link as Settings → Community → Discord.

Public issue

GitHub

Feature requests and bugs on Neighborhood-Nerd/cirrus. Don’t paste API keys or passwords into an issue.

From the app

Report a bug

In Cirrus, go to Settings → Report a bug. You need to be signed in. That files a GitHub issue with your description, optional screenshots, and recent session logs. Details are in the Privacy Policy.

Optional

Buy Me a Coffee

Support development. This is not a support desk, and it isn’t required to use Cirrus.
