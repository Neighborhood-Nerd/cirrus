01

How do I get Cirrus?

Download the latest build from GitHub Releases. Pick the file for your platform, install it, then open Cirrus.

02

What does it run on?

Cirrus is a cross-platform Flutter app. Current builds cover iPhone, iPad, Mac, Android, Windows, and Linux. CarPlay and Android Auto are also supported.

03

What is a Cirrus account?

An email-and-password account, run by Supabase. With it:

  • library shelves, listening history, clips, and settings follow you between devices;
  • provider sources and in-app bug reports are available;
  • your AudiobookDB key and downloader keys can travel with the account, so you don’t re-enter them everywhere.

Create one from the sign-in screen, or later from Profile. Check your email for the confirmation message. A build without Supabase secrets can still play local files, but it won’t offer cloud sign-in.

04

How do I add AudiobookDB?

Catalogue and shelves come from audiobookdb.org. Get an API key there (keys usually start with adb_), then paste it in Cirrus onboarding, or later under Settings → Change API key.

If you have a Cirrus account, that key is saved with the account so it syncs. Settings → Refresh shelves pulls Continue Listening, To Listen, Listened, and Favorites again. Clear API key removes it from this device.

05

How do downloaders work?

Cirrus does not download peer-to-peer on its own. For sources that need a cloud unlocker, open Settings → Downloaders and add TorBox, Real-Debrid, or Premiumize. Some of those can sign in with a device code in the browser; others take an API key.

Until a downloader is configured, those remote sources can’t fetch audio. Your key stays on the device and, with an account, in settings sync.

06

What are search providers?

Installable sources, from a provider repo you add. In Settings → Search providers, add a repo URL. The example community index lives at soundloom-providers (index.json).

Removing a repo uninstalls the sources that came from it. You are responsible for the repos you install; see the Terms of Use.

07

How do captions work?

Turn captions on from Now Playing (CC). They are made on this device, from a downloaded title. Streaming-only playback is not captioned yet.

On Apple devices that support it, Cirrus uses Apple Speech and does not need a download. Otherwise it uses Whisper: pick a model your phone can hold in RAM under Settings → Captions. A pack that is too large can crash the app. Tiny is the safer first download. Audio never leaves the device for this.

08

Does it work in the car?

Yes, as a CarPlay audio app on iPhone: browse the library and control Now Playing from the dashboard. Use a physical iPhone for in-car testing. Casting is also in the player for other speakers.

09

How do I update, or join beta?

In Settings → Check for updates, Cirrus looks at GitHub Releases. Turn on Beta updates if you also want GitHub pre-releases. You can confirm before joining beta.

10

How do I report a bug?

Best path, if you’re signed in: Settings → Report a bug. That sends a title, description, optional screenshots (up to two), and the last three session logs to GitHub. You can opt in to be mentioned with your GitHub username so GitHub notifies you.

If you’re signed out, that screen asks you to sign in. You can also open an issue yourself at github.com/Neighborhood-Nerd/cirrus/issues. Don’t paste API keys into a public issue. There is a daily cap on in-app reports.

11

How do I sign out?

Profile → Sign out. The local library on that device is cleared. Your account in the cloud stays. Sign in again on this device (or another) to pull it back.

12

How do I delete my account?

There isn’t a delete-account button in the app yet. Ask from the Contact page. We’ll delete the account and the copy stored with it. Audio files on the device you’re holding stay there until you remove the app or those files.

13

Is my listening private?

Cirrus has no ads and no analytics SDKs. Captions stay on the device. An account stores shelves, history, clips, and the keys you added so other devices can use them; that copy lives in Supabase, limited to your user id. The Privacy Policy is the full list.

14

Does Cirrus sell audiobooks?

No. Cirrus is a player. It doesn’t sell, host, or supply audiobooks. Use it with audiobooks you own, have licensed, or that are free to use. The Terms of Use say more.
